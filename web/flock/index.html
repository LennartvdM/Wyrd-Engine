Each strip is one day, midnight to midnight. Click one to open it above.

This person's weekdays, stacked

Every weekday of the run laid on top of the others: how often this one person is doing each thing at each minute. A person who repeats themselves gives hard edges; one whose days vary gives soft ones.

Segments as a table

One line per day

The chart above pools every weekday into one set of percentages. These are the days kept apart: at any minute there is a percentage for each day, so days that agree lie on top of each other and days that differ fan out. The width of that fan is the day-to-day variation — a population with none would draw a single sharp line.

The same shares, without edges

The stack above draws a boundary between every pair of activities. These do not: on the left, every column is the whole population mixed in proportion; on the right, one row per activity where stronger colour means more people.

Every day, stacked

One row per person-day, midnight to midnight. The totals above are an average and cannot show how a transition is spread; here the days themselves lie on top of each other, so a population that moves together reads as a straight edge and one that does not reads as a frayed one.

Binned shares as a table

An agent sees only what observe returns, and a reply arrives when the person gets to it: after they wake, after the meeting ends, or in a couple of minutes if they are watching television. This runs on its own copy of the world, because a ping splits the activity it interrupts and must not edit the logs shown in the other tabs.
